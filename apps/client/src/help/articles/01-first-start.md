# Перший запуск SADOK

Ця глава допоможе підготувати SADOK до щоденної роботи закладу.

## Як відкрити довідку

- Повний зміст доступний через **Про програму → Документація (Wiki)**.
- На робочих сторінках натисніть **Довідка** у верхній панелі, щоб одразу відкрити відповідну главу.
- У Wiki використовуйте пошук за назвою розділу, дією або текстом помилки.
- Вибрану главу можна надрукувати кнопкою **Друкувати главу**.

## 1. Виберіть роль компʼютера

Під час першого запуску оберіть один із режимів:

- **Сервер** — головний компʼютер, на якому зберігається база даних SADOK.
- **Клієнт** — додаткове робоче місце, яке підключається до сервера через локальну мережу.

> Для одного компʼютера обирайте режим сервера. Сервер має бути увімкнений, коли інші робочі місця користуються SADOK.

## 2. Підключіть клієнт до сервера

1. Переконайтеся, що обидва компʼютери підключені до однієї локальної мережі.
2. На клієнтському компʼютері запустіть пошук серверів.
3. Виберіть знайдений сервер SADOK.
4. Перевірте підключення та продовжте.

Якщо сервер не знайдено, дивіться главу **«Вирішення проблем»**.

## 3. Увійдіть до системи

1. Введіть початкове імʼя користувача (`admin`) та пароль (`admin123`).
2. Переконайтеся, що на клавіатурі увімкнено англійську розкладку (ENG) та вимкнено Caps Lock.
3. Після першого успішного входу обов'язково змініть початковий пароль у розділі **Налаштування → Користувачі**.
4. Не використовуйте один обліковий запис для всіх працівників.

## 4. Виконайте початкове налаштування

У розділі **Налаштування** послідовно:

1. Вкажіть назву та реквізити закладу.
2. Створіть облікові записи працівників.
3. Налаштуйте ролі та права доступу.
4. Перевірте стан ліцензії.
5. Створіть першу резервну копію.

## Контрольний результат

Після налаштування на головній сторінці відображається ваш заклад, користувачі входять під власними обліковими записами, а резервна копія створюється без помилок.
