# Звіти, сповіщення та внутрішній чат

## Формування звіту

1. Відкрийте **Звіти**.
2. Оберіть тип звіту.
3. Вкажіть період, групу або інші фільтри.
4. Сформуйте попередній перегляд.
5. Перевірте дані до друку або експорту.

Якщо показники неправильні, виправте первинні записи, а не готовий експортований файл.

## Центр сповіщень

SADOK повідомляє про події, які потребують уваги: низькі залишки, строки медикаментів, щеплення, меню та резервні копії.

- відкрийте сповіщення, щоб перейти до відповідного розділу;
- позначайте виконані завдання завершеними;
- відкладання приховує повідомлення тимчасово, але не усуває причину;
- критичні повідомлення опрацьовуйте першочергово.

## Внутрішній чат

Чат призначений для робочої комунікації між користувачами одного SADOK. Не надсилайте через нього паролі, ліцензійні токени або надлишкові персональні дані.
