# Встановлення та робота в мережі

## Серверне робоче місце

1. Встановіть SADOK на компʼютер, який буде зберігати базу.
2. Оберіть роль **Сервер**.
3. Дозвольте SADOK працювати в локальній мережі, якщо Windows покаже запит брандмауера.
4. Не вимикайте сервер під час роботи клієнтських компʼютерів.

## Клієнтське робоче місце

1. Встановіть ту саму версію SADOK.
2. Оберіть роль **Клієнт**.
3. Запустіть пошук сервера.
4. Виберіть адресу головного компʼютера.
5. Увійдіть під своїм обліковим записом.

## Вимоги до локальної мережі

- сервер і клієнти мають бути в одній мережі;
- для сервера бажано використовувати кабельне підключення;
- не змінюйте адресу сервера без потреби;
- не відкривайте порт SADOK безпосередньо в Інтернет;
- використовуйте захищений Wi‑Fi із надійним паролем.

## Перенесення сервера

1. Створіть ручну резервну копію на старому сервері.
2. Збережіть архів на зовнішньому носії.
3. Встановіть SADOK на новому компʼютері як сервер.
4. Відновіть базу через штатний інструмент SADOK.
5. Перевірте дітей, користувачів, меню та останні записи.
6. Перепідключіть клієнтські робочі місця до нового сервера.

> Не копіюйте відкритий файл бази вручну. Використовуйте резервне копіювання та відновлення SADOK.
