# Ліцензія та оновлення SADOK

## Активація

1. Відкрийте **Налаштування → Ліцензія**.
2. Скопіюйте код запиту, якщо активація потребує підтвердження адміністратором.
3. Після підтвердження запустіть перевірку активації.
4. Або введіть отриманий ключ чи токен у відповідне поле.
5. Перевірте тип ліцензії та строк дії.

Ліцензійний токен привʼязаний до компʼютера. Не публікуйте його та не надсилайте стороннім особам.

## Зміна строку ліцензії

Перед перевіркою переконайтеся, що компʼютер має доступ до Інтернету, а в SADOK увійшов користувач.

Після перевипуску токена активований SADOK періодично перевіряє сервер у фоновому режимі та автоматично отримує новий строк. Сторінку **Налаштування → Ліцензія** тримати відкритою не потрібно. Повторно вводити вже використаний короткий ключ також не потрібно.

Очікуваний результат: протягом приблизно однієї хвилини в SADOK зʼявиться новий тип ліцензії або строк її дії.

## Відкликання ліцензії або пристрою

Якщо адміністратор ліцензій відкликав ліцензію чи активацію цього компʼютера, SADOK отримає новий статус під час фонової перевірки та видалить локальний токен. Після цього доступ залежатиме від залишку початкового 14-денного пробного періоду.

Щоб відновити роботу, адміністратор ліцензій має дозволити активацію та видати новий ключ. Старий короткий ключ після відкликання використовувати не можна.

Важливо: якщо сервер Активатора тимчасово недоступний, SADOK не видаляє чинну локальну ліцензію лише через помилку мережі. Статус буде застосовано після відновлення звʼязку.

## Код компʼютера

Код компʼютера зберігається локально під час першого запуску серверної частини SADOK. Зміна імені компʼютера на Windows або macOS після цього не змінює код активації. Видалення всіх даних SADOK, включно зі службовими файлами серверної частини, може створити новий код і потребуватиме повторної активації.

## Перевірка оновлень

1. Відкрийте **Про програму**.
2. Натисніть **Перевірити оновлення**.
3. Дочекайтеся результату.
4. Перед встановленням створіть резервну копію.
5. Не вимикайте компʼютер під час встановлення.

## Перед зверненням щодо ліцензії

Підготуйте код запиту, версію SADOK і точний текст помилки. Не надсилайте пароль адміністратора або повний приватний токен у відкритому листуванні.
