# Ліцензія та оновлення SADOK

## Активація

1. Відкрийте **Налаштування → Ліцензія**.
2. Скопіюйте код запиту, якщо активація потребує підтвердження адміністратором.
3. Після підтвердження запустіть перевірку активації.
4. Або введіть отриманий ключ чи токен у відповідне поле.
5. Перевірте тип ліцензії та строк дії.

Ліцензійний токен привʼязаний до компʼютера. Не публікуйте його та не надсилайте стороннім особам.

## Зміна строку ліцензії

Після перевипуску токена активований SADOK періодично перевіряє сервер і автоматично отримує новий строк. Повторно вводити вже використаний короткий ключ не потрібно.

## Перевірка оновлень

1. Відкрийте **Про програму**.
2. Натисніть **Перевірити оновлення**.
3. Дочекайтеся результату.
4. Перед встановленням створіть резервну копію.
5. Не вимикайте компʼютер під час встановлення.

## Перед зверненням щодо ліцензії

Підготуйте код запиту, версію SADOK і точний текст помилки. Не надсилайте пароль адміністратора або повний приватний токен у відкритому листуванні.
