# Працівники та документи

## Додавання працівника

1. Відкрийте розділ **Працівники**.
2. Створіть нову картку.
3. Заповніть ПІБ, посаду, контакти та дату прийняття.
4. Додайте необхідні кадрові відомості.
5. Збережіть картку.

## Документи працівника

У картці працівника можна вести повʼязані документи. Для кожного документа вкажіть тип, номер, дату та строк дії, якщо він обмежений.

## Передача майна

1. Відкрийте картку працівника або розділ майна.
2. Оберіть одиницю майна.
3. Зафіксуйте передачу відповідальній особі.
4. Перевірте поточного відповідального в картці майна.

## Звільнення

1. Перевірте майно, закріплене за працівником.
2. Передайте або поверніть його.
3. Змініть статус працівника.
4. Вимкніть його обліковий запис у налаштуваннях користувачів.

> Видалення картки може знищити важливий історичний звʼязок. Якщо доступно, використовуйте статус неактивного працівника.
